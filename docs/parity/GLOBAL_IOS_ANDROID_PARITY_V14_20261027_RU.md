# iumrah · Android ↔ iOS · Глобальный аудит и PATCH v14

**Дата:** 27 октября 2026 г.  
**Исходное состояние Android:** первоначальный `kepler-android-main.zip` + v5 (установленный фирменный стиль) + v13 (подтверждён пользователем).  
**Эталон iOS:** исходный `kepler-ios-main 3.zip` с учётом отдельно предоставленного `iumrah_headers_and_world_dots_2in1_patch.zip` (временно объединён только в копии для анализа).  
**Изменения:** только Android; iOS-архив и исходники iOS не редактировались.  
**Исключение:** Umrah Flow (ритуальные экраны, стадии и анимации) не является целью синхронизации.

## 1. Содержание исправлений v14

### 1.1. Восемь языков по iOS

Раньше Android поддерживал четыре языка. Модель `AppLanguage` теперь включает все восемь языков, которые перечислены в `IumrahLanguageSelectionSheet.swift`:

| Язык | Код | Локаль |
|---|---|---|
| Русский | `ru` | `ru-RU` |
| English | `en` | `en-US` |
| العربية | `ar` | `ar-SA` |
| Türkçe | `tr` | `tr-TR` |
| Bahasa Indonesia | `id` | `id-ID` |
| Bahasa Melayu | `ms` | `ms-MY` |
| O‘zbekcha | `uz` | `uz-Latn-UZ` |
| Ўзбекча | `uz-cyrl` | `uz-Cyrl-UZ` |

**Переводы взяты из iOS, не придуманы:**

| Каталог iOS | Ключевые строки | Переводы фраз |
|---|---:|---:|
| ArabicLocalization | 553 | 1 066 |
| TurkishLocalization | 553 | 2 546 |
| IndonesianLocalization | 34 | 23 |
| MalayLocalization | 45 | 7 |

Для строк, отсутствующих в соответствующем официальном словаре iOS, остаётся **английский fallback, как в iOS**. Это значит, что часть текста на малайском и индонезийском по-прежнему выводится по-английски **и в iOS**; неверно было бы обещать перевод каждого предложения.

- `L10n.text` сначала обращается к каталогу утверждённых переводов по ключу, затем к переводу английской фразы, затем к английскому оригиналу.
- Дополнительные локализаторы экранов используют каталоги фраз вместо безусловного английского там, где Swift делает аналогичный fallback.
- Приведены в порядок явные `when`-конструкции Android, ранее рассчитанные на четыре языка.
- В 13 местах дата / календарь используют выбранную системную локаль вместо английской.
- Арабский интерфейс получил RTL-расположение на уровне всего приложения, а не только одного экрана.

### 1.2. Экран выбора языка

Теперь Android повторяет ключевой сценарий `IumrahLanguageSelectionSheet.swift`:

- восемь языков в том же порядке, с нативными названиями и подписями;
- оригинальное изображение `LanguageSelectionHero.jpg` из iOS (побайтовая копия исходного ресурса);
- отмечены текущий и предварительно выбранный язык;
- переключение происходит **только после подтверждения**, а не после простого нажатия на строку;
- локализованы заголовок, описание, подсказка и подтверждение;
- типографика Android остаётся Lato, в соответствии с согласованным исключением.

Точный рендеринг этой страницы ещё должен быть сопоставлен скриншотами, включая нижний safe area и длинные подписи в арабском режиме.

## 2. Глобальные компоненты: результаты проверки исходников

| Область | Подтверждено по исходникам | Что НЕ подтверждено |
|---|---|---|
| Lato | Глобальная Compose `FontFamily`, Lato Regular/Bold и дополнительные веса подключаются при сборке | Отсутствует проверка фактического рендеринга шрифтов на устройствах |
| Cupertino Icons | Android-каталог использует официальный шрифт Cupertino, **не** ручные Path/Canvas-рисунки глифов | Глифы Cupertino не являются идентичными оригинальным Apple SF Symbols во всех случаях |
| SF Symbols | Все **133** статически заданных `Image(systemName: "…")` из iOS имеют имена в Android-каталоге; всего **204** зарегистрированных соответствия | Динамические имена и пиксельная геометрия всех символов отдельно не подтверждены |
| Параметры карточек | Базовые значения Android соответствуют зафиксированным исходным iOS-константам: 18, 28, 34, 19, 56, 46 | Фактические координаты, высота текста, тени, плотность пикселей, скролл-эффекты не измерены на устройствах |
| Фирменные хедеры | Блок 1 с точечной картой и монохромной навигацией сохранён без правок v14 | Идентичность скорости/яркости всех шейдеров на разных Android GPU не подтверждена |
| Liquid Glass | Сохранено согласованное платформенное исключение | Нативную реализацию iOS невозможно буквально использовать на Android |
| Umrah Flow | Исходные файлы ритуального модуля не затронуты | Вне рамок синхронизации по прямому указанию |

**Важно:** проверка покрытий имён SF Symbols не равнозначна визуальному совпадению иконок 1:1. Ранее выявлялись неоднозначности между некоторыми fill/outline-вариантами. Они остаются открытой визуальной проверкой.

## 3. Проверки и ограничения

### Что действительно выполнено

1. Восстановление исходного Android + v5 + v13 с проверкой побайтового применения нового патча.
2. Все существующие структурные этапы `verify-stage25.sh` (каскадно включая предыдущие).
3. Дополнительные проверки v14: языковые коды, RTL, экран подтверждения, каталоги, общий шрифт, иконки, 166 явно проверяемых language-switch-конструкций.
4. Разбор синтаксиса всех **149 Kotlin-файлов** штатным Kotlin PSI: **0 ошибок**.
5. Изолированная компиляция Kotlin-каталогов переводов и функциональные проверки восьми языков / английского fallback.
6. Проверка ZIP-структуры, контрольных сумм и отсутствие копирования файлов iOS в Android-патч.

### Что ещё требуется для объективного «100%»

1. **Полная Gradle / Android SDK сборка** Debug/Release и проверка ресурса Cupertino и Lato после bootstrap. В рабочем окружении не установлен Android SDK/Gradle; статический анализ не заменяет сборку.
2. **Скриншоты** iOS/Android с согласованной шириной, scale, светлой/тёмной темой, состояниями и одинаковыми тестовыми данными. Проверить заголовки, каждую карточку, градиенты, иконки, кнопки, анимации, клавиатуру и safe areas.
3. **E2E сценарии**: пользовательский вход, поиск, фильтры, конфигуратор, получение цены, создание брони, чат, оплата (в тестовой среде), eSIM, push, deeplink, выбор языка и RTL.
4. **Визуальная сверка всех динамических состояний:** пустые списки, загрузка, ошибка сети, длинный текст и RTL; тесты на разных Android API / плотностях.
5. **Иконки:** провести визуальную проверку всех реально показанных Cupertino-символов; только если найден официальный близкий вариант, менять сопоставление. Apple SF Symbols как шрифт не включаются в Android.

В результате этот PATCH — проверенное **исправление исходников и локализации**, но **не сертификат визуальной идентичности 1:1**.

## 4. Установка

1. **База:** репозиторий, в который уже применён v13 (и до него v5). Не устанавливать v6–v12 заново.
2. Загрузить в корень GitHub Android-репозитория **только** `iumrah-android-update-20261027-v14.zip` через **Add file → Upload files → Commit changes**. **Не распаковывать** архив до загрузки в GitHub.
3. GitHub workflow `iumrah Android CI` удалит ZIP после применения и закоммитит изменённые исходники. Убедиться, что операция `apply-update` прошла.
4. Затем открыть **Actions → iumrah Android CI → Run workflow** и проверить успешную Debug-сборку и APK. Эта сборка обязательна до выпуска в Google Play.
5. После сборки выполнить устройства/скриншоты и сравнение с iOS. Только после этого можно закрывать финальную приёмку.

**Не меняйте iOS-репозиторий на основании этого PATCH.**
