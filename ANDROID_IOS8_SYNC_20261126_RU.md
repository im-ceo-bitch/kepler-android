# Android / iOS 8 — накопительная синхронизация

Эталон: kepler-ios-main 8.zip, предыдущий эталон: kepler-ios-main 7.zip. Новый архив не имеет полного центрального оглавления; прочитаны 1485 локальных ZIP-записей, каждая проверена по CRC и размеру. Полнота архива как оригинала не может быть гарантирована. Сравнение восстановленного дерева выявило 11 изменённых Swift-файлов.

## Изменения
- Home: два контекстных списка опубликованных рейсов, ранжирование по маршруту, классу, совместимости и локальной дате; будущие альтернативы остаются в каталоге, цены без достоверного USD-тарифа не используются для покупки. Переход всех билетов в штатный подбор. Порядок секций, возврат Smart, переход к отелям только при совместимых сегментах.
- Карточки рейсов Home и guided: 224dp минимальная высота с учётом масштаба текста, 14dp внутренние отступы, 42dp заголовок, 76dp центральная колонка, 35dp строка стоимости.
- Dashboard и Account: монохромная палитра, планировщики, сервисы, гиды, Friends/Rewards. Купоны Friends остаются после входной анимации.
- Guide: компактные аватары и профили, данные из backend.
- Smart при первом запуске: существующий сценарий Smart вместо старого welcome onboarding, сохранение гостевого черновика с контролем владельца.
- Сохранение пакета: только с действительным quote ID, одна повторная котировка при QUOTE_EXPIRED или BOOKING_QUOTE_REFRESH_REQUIRED, без принудительного обновления каталога отелей. Изменённая цена требует явного подтверждения. Проверяется неизменность черновика перед привязкой результата.

## Проверки
- Комплекс Stage 25 прошёл на промежуточной версии до заключительных правок карточек и первого запуска. После заключительных правок: Kotlin PSI 280 файлов без синтаксических ошибок; source guards Home, Hotels/Flights и Configurator; 37 сравнений source guard с текущим Swift; JVM тест каталога (10 проверок, 400 рейсов); JVM ranking (9 проверок извлечённых production rules с минимальным TripDraft-заглушкой).
- Дополнительная историческая проверка verify-block3-home-parity.py --ios не прошла по старому условию геометрии trip tools, которое не соответствует актуальному Swift. Это не доказательство визуальной эквивалентности.
- Gradle/Compose type checking, APK, запуск на реальном устройстве, сравнение скриншотов и live API не проверены. Нативные SwiftUI эффекты приближены, но не сертифицированы. Сохраняются различия первой навигации Smart, отдельных системных inset/guide header и общих компонентов/анимаций. Полный 1:1 не подтверждён.

Накопительный архив предназначен для наложения на исходный Android. Все прежние файлы патча включены, workflows не менялись. Не применять предыдущие ZIP отдельно.
