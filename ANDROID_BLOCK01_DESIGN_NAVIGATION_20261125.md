# Block 01 — Design System & navigation / 2026-11-25

## Scope
Cumulative patch over `kepler-android-main 2.zip`; includes all previous nonhome-v1 payload files (Smart, Trip Summary, account and public links) so the shell continues to compile against the same contracts. Block 01 adds shared style, navigation and adaptive behavior. It does not certify individual commercial/ritual screens or change the Home dashboard composition. `ui/home/` and `ui/homeflow/` are byte-identical to the original 14 files; all four existing GitHub workflows are byte-identical. Shared code takes its original branch when rendering Home root, including the original compact bottom bar and drawer. A new screen opened from Home is not Home root and receives the parity style. Actual Android before/after Home screenshots are still required.

## Source contracts and changes
- `Views/RootView.swift` actually uses native `TabView` tinted with `.umrah`, not the unused monochrome `IumrahStoreTabBar`. Non-Home compact tabs use theme-aware glass-like layered chrome, teal selected tint, source labels/icons and width-measured labels. Geometry, animation, SF symbol rendering and system glass remain approximations, not pixel identity. Home keeps its original monochrome bar.
- `Core/AdaptiveLayout.swift` and `AppShell/IumrahAdaptiveAppShell.swift`: <700 compact, 700–999 regular, >=1000 wide, ideal sidebar 268; re-evaluate readable width from detail column; no Catalyst profile on Android. Home root exempt. Menu hidden when a sidebar is present; services use existing Home-owned eSIM and notification routing. Footer avoids claiming online without observed connectivity.
- `Core/DesignSystem.swift`: existing 18/28/34/19/56/46 geometry and type tokens preserved; non-Home content surface and dark raised surface, continuous-corner approximation on shared cards, capsule CTA press behavior, glass-like chrome and back-button touch feedback. Shared header group uses one surface; ordinary content does not become glass. Native system fonts and licensed Cupertino glyphs remain; no Apple font binaries imported. Non-Home pill scrolling respects reduced motion.
- `AppShell/AppNavigationContainer.swift`: independent tab stacks retained; non-sensitive details now have per-tab opaque saveable-state keys, popped destinations are pruned, identity/payment/token routes excluded from additional retention. Keys are deliberately in-memory and do not promise recovery after process death. Existing Home transitions retained; non-Home routes use directional push/pop approximations and reduced-motion fallback. System interactive edge-swipe physics still need runtime comparison.
- Root masthead visibility cannot be reported by an outgoing tab into the incoming tab; non-Home dark-mode status icons follow the actual page background; original Home status treatment retained. Tablet status strip mirrors detail status colors. Existing old static guards updated to check the actual scoped implementation, not removed. Rate-state guard now checks existing `markMissing` behavior rather than the obsolete expression; hotel pricing logic unchanged by Block 01.

## Apply
Upload the cumulative ZIP to the Android repository root (the existing workflow matches `iumrah-android-update-*.zip`). Do not edit CI or manually unpack if using the existing workflow.
